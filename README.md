# Цитата из Библии

Программа показывает случайные стихи из Библии на Python + PyQt6.

## Возможности
- Смена стиха каждые 30 минут (интервал настраивается)
- Стихи не повторяются, пока не покажутся все
- Ручная смена стиха кнопкой 🎲
- Лайк кнопкой 👍 (❤️ — лайк поставлен, повторное нажатие снимает его)
- История показов и лайков сохраняется в базу SQLite
- Курсив из базы (теги `<i>`) отображается как в печатном издании
- Ссылка на место Писания (книга, глава, стих) — серым шрифтом поменьше
- Прокрутка длинных стихов
- Тёмная тема

## Зависимости

Нужен Python 3 и PyQt6 (модуль sqlite3 входит в состав Python):

```
py -m pip install PyQt6
```

## Подготовка базы данных

Рядом со скриптом должен лежать файл `RST77.SQLite3` — база Синодального
перевода с таблицами `verses` и `books`. Ничего создавать и заполнять
вручную не нужно.

База истории `bible_history.db` с таблицей
`history (text, short_name, chapter, verse, date_time, liked)`
создаётся автоматически при первом запуске.

У программы с анекдотами своя база истории (`history.db`), поэтому
программы можно запускать одновременно — они не мешают друг другу.

## Запуск

```
py main.pyw
```

## Настройка

Константы в начале файла:
- `INTERVAL` — интервал смены стихов в секундах (1800 = 30 минут)
- `BUTTON_SIZE`, `BUTTON_FONT_SIZE` — размер кнопок и значков на них
- `BIBLE_DB`, `HISTORY_DB`, `ICON_PATH` — пути к базам и иконке
